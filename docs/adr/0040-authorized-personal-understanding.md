# ADR 0040: Authorized personal understanding

Recorded 2026-09-19 during implementation. This record describes the final design;
the earlier implementation plan contains the pre-implementation scope.

Personal understanding is a projection of the Context Broker packet, not a second
truth store. Current applicability, historical confidence, question relevance and
retention have independent authority. Freshness binds to original same-fact
evidence and an immutable registry policy. Unsupported semantics stay unknown.

Candidate retrieval uses authorized semantic matches and bounded metadata scans.
Readable frames consume the answer budget; denied frames can supply only bounded
redaction placeholders. Provenance ceilings propagate an incomplete-view marker.
Stored context never grants continuing access after source permission or removal
changes.

Transitions use recorded claim relations, preserving effective and recorded dates.
A relation without recorded rationale does not acquire a guessed motive. Old
decision rationale remains a historical answer, even after its interval ends.
Model origins remain distinct from owner statements. Unfinished obligations need
supported outcomes, not a timeout or lack of recent discussion.

Goal relevance requires both a sourced association and active goal authority.
Migration0034 exposes only owner-bound goal IDs and priorities at the requested
world/knowledge times. It reads append-only history rather than mutable priority
caches; paused, unavailable and retired goals cannot justify current focus.

Generic capability and no-goal guidance assert no personal fact and carry an
UNKNOWN memory label. A sourced recommendation cites its actual supporting
objects. Ask's relative change windows currently state UTC boundaries because the
request contract does not declare a personal time zone; explicit time windows
take precedence. Today and initiative use the owner's declared time zone.
